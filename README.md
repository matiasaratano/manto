# Manto Administración
Sitio estático con HTML, CSS y JavaScript, sin dependencias. Abrir index.html o servir la raíz con cualquier servidor estático.

## Páginas
- index.html: portada de Manto, servicios, propiedades, proceso y contacto.
- propiedades.html: catálogo inicial y espacios para enlaces externos.
- la-casita.html: ficha inicial de La casita.
